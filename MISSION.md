# Mission: Defend the SkinCare AI Final-Year Project

## Why
Build enough understanding of this project to explain and defend it honestly in a final-year viva, write a technically accurate report, and deliver a reliable demonstration within two weeks.

## Success looks like
- Explain the complete image-to-recommendation pipeline without notes.
- Explain the important AI, data, evaluation, API, and application concepts in beginner-friendly language.
- Justify major design decisions and discuss limitations without overstating the results.
- Write the methodology, architecture, results, ethics, and limitations sections of the report.
- Demonstrate the system and answer likely examiner follow-up questions.

## Constraints
- The learner is a Python and software-development beginner.
- Fewer than two weeks remain before submission or viva.
- Lessons should emphasize theory and system reasoning before code details.
- Every lesson should include retrieval practice and viva questions.

## Out of scope
- Becoming an expert Python, React Native, TensorFlow, or backend developer before the viva.
- Memorizing every source-code line.
- Making medical or clinical claims that the project evidence cannot support.
