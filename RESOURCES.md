# SkinCare AI Project Resources

## Knowledge

- [Google Machine Learning Crash Course](https://developers.google.com/machine-learning/crash-course)
  Beginner-friendly foundation for models, classification, neural networks, and evaluation. Use throughout the first week.
- [Google Machine Learning Glossary](https://developers.google.com/machine-learning/glossary)
  Authoritative definitions for unfamiliar AI terms. Use when reviewing lesson vocabulary.
- [TensorFlow: Transfer Learning and Fine-Tuning](https://www.tensorflow.org/tutorials/images/transfer_learning)
  Official explanation of pretrained backbones, frozen layers, and fine-tuning. Use for the EfficientNet training lesson.
- [Keras EfficientNet API](https://keras.io/api/applications/efficientnet/)
  Official model-family documentation. Use for the vision architecture and preprocessing discussion.
- [Keras: Multi-Label Classification](https://keras.io/examples/nlp/multi_label_classification/)
  Official example showing independent labels and sigmoid-style multi-label reasoning. Use to contrast multi-label and multi-class tasks.
- [scikit-learn: Model Evaluation](https://scikit-learn.org/stable/modules/model_evaluation.html)
  Definitions and implementation notes for precision, recall, F1, ROC-AUC, and average precision. Use for evaluation and threshold lessons.
- [FastAPI Tutorial](https://fastapi.tiangolo.com/tutorial/)
  Official guide to routes, validation, uploads, errors, and API structure. Use for the backend lesson.
- [Hugging Face LLM Course](https://huggingface.co/learn/llm-course/chapter1/1)
  Official introduction to Transformers and language-model inference. Use for the Qwen SLM lesson.
- [Hugging Face Transformers Documentation](https://huggingface.co/docs/transformers/index)
  Official reference for loading pretrained models and generating text. Use when explaining the SLM engine.
- [Streamlit Fundamentals](https://docs.streamlit.io/get-started/fundamentals/main-concepts)
  Official explanation of Streamlit's rerun and state model. Use for the web-interface lesson.
- [Expo Tutorial](https://docs.expo.dev/tutorial/introduction/)
  Official introduction to the mobile framework used by the project. Use for the application-integration lesson.
- [React: Describing the UI](https://react.dev/learn/describing-the-ui)
  Official conceptual introduction to components and interfaces. Use only for the minimum mobile-app theory needed for the viva.
- [WHO: Ethics and Governance of Artificial Intelligence for Health](https://www.who.int/publications/i/item/9789240029200)
  High-trust guidance on safety, accountability, and evidence for health-related AI. Use for ethics, limitations, and report writing.

## Wisdom (Communities)

- [Data Science Stack Exchange](https://datascience.stackexchange.com/)
  Moderated technical question-and-answer community. Use to test precise questions about metrics, validation, and modeling choices.
- [AI Stack Exchange](https://ai.stackexchange.com/)
  Moderated community for conceptual AI questions. Use when a design tradeoff needs perspectives beyond documentation.
- University supervisor and project examiner
  Primary source for institution-specific report format, assessment criteria, and acceptable project claims.
